# Worklog 색인

## 현재 상태
- 진행 중: 관제 앱 1단계(서버 + 레이더 화면) 완료, 시뮬레이션 실행 확인 전 ([app](app.md)). 8단계 실제 로봇은 휴대폰 알림까지 성공 ([real-robot](real-robot.md)).
- 다음 할 일: 앱 1단계 커밋 → 가상머신 시뮬레이션에서 앱 확인 → 앱 2단계(조이스틱 수동 주행)
- 사용자 결정 대기: 커밋·푸시 승인(앱 1단계, worklog, 영상 이미지)
