# Worklog 색인

## 현재 상태
- 진행 중: 6단계 경보까지 VM 시험을 통과했다(코드 `86249d4`). 걷는 침입자 하나에 휴대폰 알림이 주의 1번, 긴급 1번만 갔다. 이 결과 worklog는 커밋 전이다.
- 5-3 사람 후보를 구현해 맥 시험 68개와 가짜 라이다 측정을 통과했다. VM에서 침입자는 사람 후보, 상자는 아님을 확인했다. 첫 알림 문구에 사람 후보가 빠지는 순서 문제를 고쳐 올렸다 ([detection](detection.md)).
- 다음 할 일: 순서 수정 VM 확인 → 7단계 통합 시험 → 제출 서류와 증빙 캡처 → 8단계 실제 로봇
- 사용자 결정 대기: 없음
